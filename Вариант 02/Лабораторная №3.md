## Задание 1. Исправьте программу

Программа обрабатывает токи нагрузки за смену: считает средний ток, энергию, наибольшую мощность и наибольший ток, часы с током выше допустимого и потери в линии.

В программе три ошибки. Из-за одной программа останавливается с сообщением об ошибке, две другие дают неверный результат без сообщений. Найдите и исправьте все три.

```julia
# Токи нагрузки за смену
I = [16.5, 12.5, 17.75, 8.25, 12.75, 17.5, 13.75, 12.5, 11.0, 8.5]   # ток по часам, А
U = [220, 224, 216, 218, 226, 220, 220, 218, 218, 220]   # напряжение по часам, В
I_доп = 12        # допустимый ток, А
R_л = 0.2        # сопротивление линии, Ом

# средний ток
сумма = 0
for i = 1:length(I)
    сумма = 0
    сумма += I[i]
end
println("Средний ток: ", round(сумма / length(I), digits = 2), " А")

# мощность и энергия (каждый замер — 1 час)
P = U .* I ./ 1000      # кВт
println("Энергия за смену: ", round(sum(P), digits = 3), " кВт·ч")
println("Наибольшая мощность: ", maximum(P), " кВт, час ", argmax(P))

# наибольший ток и час
I_макс = I[1]
час = 1
for i in 2:length(I)
    if I[i] > I_макс
        I_макс = I[i]
        час = i
    end
end
println("Наибольший ток: ", I_макс, " А, час ", час)

# часы выше допустимого тока и часы ниже среднего
часы_выше = часы_ниже = Int[]
I_ср = sum(I) / length(I)
for i in 1:length(I)
    if I[i] > I_доп
        push!(часы_выше, i)
    elseif I[i] < I_ср
        push!(часы_ниже, i)
    end
end
println("Часы выше допустимого тока: ", часы_выше)
println("Часы ниже среднего тока: ", часы_ниже)

# потери в линии
потери = sum(I ^ 2 .* R_л)      # Вт·ч
println("Потери в линии: ", round(потери, digits = 1), " Вт·ч")
```

**Контрольные значения**

- Средний ток: 13.1 А
- Энергия за смену: 28.812 кВт·ч
- Наибольшая мощность: 3.85 кВт, час 6
- Наибольший ток: 17.75 А, час 3
- Часы выше допустимого тока: [1, 2, 3, 5, 6, 7, 8]
- Часы ниже среднего тока: [4, 9, 10]
- Потери в линии: 363.8 Вт·ч
